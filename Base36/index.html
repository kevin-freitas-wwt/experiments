Base36

Hex runs out at F. Keep going to Z and every one of the 36 characters you can type without shift becomes a digit.

Same idea as hexadecimal: each place is worth 36 times the one to its right. 0–9 keep their values, A is 10, B is 11, and Z is 35. A billion fits in six glyphs; a Unix timestamp in eight.

Convert

Place values

Read right to left. Each glyph is multiplied by 36 raised to its position, and the products add up to the decimal value.

Same number, four alphabets

The bigger the alphabet, the shorter the number. Base 36 gets roughly 5.17 bits per glyph, against 4 for hex.

Use it on your own site

One file, no dependencies, under 4 KB. Works as a plain script, a CommonJS module, or inside a worker. Download base36.js.

<!-- plain script: exposes window.Base36 -->
<script src="base36.js"></script>

// or in Node / bundlers
const Base36 = require( "./base36.js" );

Base36.encode( 1295 );            // "ZZ"
Base36.encode( 3.75 );            // "3.R"
Base36.encode( 2n ** 80n );       // "5GV2RMA270X9HHJ4" (BigInt in, exact out)
Base36.decode( "HELLO" );         // 29234652
Base36.decodeBig( "ZZZZZZZZZZ" ); // 3656158440062975n
Base36.places( "1Z" );            // [ { glyph: "1", value: 1, exponent: 1, weight: 36n, product: 36n }, ... ]
FunctionDoes
encode( value, places = 8 )Number, BigInt or numeric string to base 36. Fractions are kept to places glyphs after the point.
decode( text )Base 36 string to a Number. Case-insensitive, accepts a sign and a fractional part.
decodeBig( text )Base 36 string to a BigInt, exact at any length. Whole numbers only.
places( text )Per-glyph breakdown: value, exponent, weight and product. Whole places are BigInt, fractional ones Number.
normalize( text )Uppercase, strip leading and trailing zeros.
isValid( text )True if the string parses.
glyphOf( n ), valueOf( g )Single-digit helpers. ALPHABET and BASE are exposed too.
Part of experiments by Kevin. JavaScript already ships n.toString( 36 ) and parseInt( s, 36 ); this adds BigInt, fractions, validation and the breakdown.
