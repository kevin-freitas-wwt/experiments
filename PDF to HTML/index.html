pdf-to-html

A Claude skill that converts any PDF into a clean, semantic HTML/CSS document — no markup soup, no absolute positioning. Content images and the source palette carry over, every page ships with mobile and print stylesheets, and an automated verification loop diffs the HTML's content flow against the PDF until it matches.

Download the skill.skill file — install in Claude via Save skill

How it works

  1. 1 · Read the PDFText, tables, and page renders are extracted and inspected; scanned documents get OCR first.
  2. 2 · Carry images & paletteContent images are triaged from decorative artifacts and placed in reading order; dominant colors become CSS custom properties.
  3. 3 · Author semantic HTMLReal headings, tables, lists, and figures in the PDF's reading order — with base, mobile, and print CSS tiers. Optional sticky section nav.
  4. 4 · Verify the flowA comparison script aligns both documents word-by-word (column-aware) and iterates until the flow score passes, with every exclusion documented.
